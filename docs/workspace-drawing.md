# 펜·지우개

## 사용

- 왼쪽 도구 막대 아래쪽의 펜(`P`)과 지우개(`E`)로 캔버스 배경에 손으로 그린다.
  - 같은 버튼을 다시 누르거나 `Esc`를 누르면 선택 모드로 돌아간다.
  - 하위 캔버스로 이동해도 고른 도구는 유지된다.
- **펜:**
  - 도구 막대 옆 칸에서 색(연결선과 같은 8색)과 굵기(가늘게 2 · 보통 4 · 굵게 8, 캔버스 단위)를 고른다.
  - 마지막 선택은 이 브라우저에만 기억한다(`pen-settings.ts`, localStorage `nono:pen`).
  - 클릭만 하면 점이 남는다.
- **지우개:** 화면 기준 반지름 10px 원 안에 든 부분만 지운다. 선 중간을 지우면 선이 둘로 나뉜다.
- 그림은 노드와 연결선 **아래**에 깔리고, 노드가 그림을 가린다.
- 펜·지우개 모드에서는 노드 위에 투명한 입력 판을 깔아 노드 선택·드래그를 막는다.
  - Space + 드래그, 휠 클릭 드래그, 휠 확대·축소는 그대로 동작한다.
- Undo/Redo는 선 하나 또는 지우개로 한 번 문지른 것 전체가 한 단계다. 아무것도 지우지 못한 문지르기는 이력에 남지 않는다.

## 데이터

```ts
WorkspaceDocument.drawing?: { strokes: DrawingStroke[] }
DrawingStroke = { id, color: ConnectionColor, width: 2 | 4 | 8, points: number[] } // [x0, y0, x1, y1, …]
```

- 공간(하위 캔버스)마다 따로 저장하고, 자동 저장을 그대로 탄다. `drawing`이 없는 이전 문서는 그림 없음으로 연다.
- 점은 소수 첫째 자리로 반올림한다.
  - 그리는 동안에는 화면 1.5px보다 가까운 점을 버린다.
  - 손을 뗄 때 RDP로 선을 단순하게 다듬는다.
- 한도와 넘었을 때 동작:

  | 대상 | 최대 | 넘으면 |
  | --- | --- | --- |
  | 공간 하나의 선 | 3,000개 | 알림을 띄우고 그리지 않는다 |
  | 선 하나의 점 | 4,000개 | 그 지점에서 선이 더 이어지지 않는다 |
  | 프로젝트 전체의 점 | 30만 개 | 알림을 띄우고 그리지 않는다 |

  지우개로 선이 나뉘어 선 한도를 넘으면 그 문지르기는 반영하지 않는다.
- 스키마(`workspace-schema.ts`) 검사 항목:
  - 색·굵기 값
  - 짝수 개·유한한 좌표
  - 선 ID 중복
  - 위 한도

## 구조

- **`drawing.ts`:** React 없는 기하 함수와 한도 상수. 화면·스키마가 함께 쓰고 `scripts/test-drawing.ts`가 검사한다.
  - `appendPoint`, `simplifyPoints`, `strokePath`, `eraseStrokes`
  - `countStrokePoints`, `countDocumentDrawingPoints`
- **`eraseStrokes`:**
  - 각 선을 지우개 반지름/2 간격으로 촘촘히 나눈 뒤, 지우개 경로와의 거리가 `반지름 + 선 굵기/2` 이하인 점을 지운다.
  - 남은 연속 구간마다 새 선을 만든다.
  - 닿지 않은 선은 같은 객체로 남는다.
- **`drawing-layer.tsx`:** 캔버스 변환 안, 연결선보다 아래의 SVG. 그리는 중인 선도 여기서 그린다.
- **`draw-options.tsx`:** 펜 색·굵기 라디오.
- **`workspace.tsx`:**
  - `tool` 상태와 `draw`·`erase` 제스처를 둔다.
  - 선과 지우기는 포인터를 누른 순간의 공간 경로에 적용한다. 그래서 그리는 도중 주소가 바뀌어도 다른 공간에 섞이지 않는다.

## 알려진 한계

- 펜·지우개 모드에서는 노드를 조작할 수 없다.
- 대시보드 미리보기에는 그림이 나오지 않는다.
- 지우개 경계는 반지름/2 간격으로 잘려 아주 정밀하지는 않다.
- 그림 전체 지우기, 형광펜, 그림 선택·이동은 없다.
