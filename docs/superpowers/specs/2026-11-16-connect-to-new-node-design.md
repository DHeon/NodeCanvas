# 빈 곳에 놓으면 새 노드로 잇기 · 우클릭 기본 메뉴 막기 (짧은 설계)

## 의도

생각을 이어 쓸 때 "연결점에서 끌어 빈 곳에 놓기 → 노드 종류 고르기" 한 번으로 이어진 새 노드를 만든다. 캔버스에서는 브라우저 우클릭 메뉴가 작업을 방해하지 않게 막는다.

## 동작

- **우클릭:** 작업 영역(도구 막대·캔버스·속성 패널)에서 브라우저 기본 메뉴를 막는다. 글을 쓰는 칸(입력칸·본문)에서는 붙여넣기·맞춤법 때문에 그대로 둔다(내 판단).
- **빈 곳에 놓기:** 연결선을 연결점도 노드도 아닌 빈 곳에서 놓고, 시작점에서 화면 8px 이상 끌었으면 그 자리에 노드 종류 메뉴(텍스트·이미지·캔버스·링크)가 뜬다.
  - 메뉴가 떠 있는 동안 놓은 자리까지 점선 미리보기를 남긴다.
  - 고르면 새 노드를 만들고 선을 이은 채 새 노드를 선택한다. 노드와 선은 실행 취소 한 단계다. 텍스트 노드는 바로 본문에 쓸 수 있다.
  - `Esc`, 메뉴 밖 누르기, 휠, 다른 공간으로 이동하면 아무것도 만들지 않고 닫는다.
  - 메뉴는 `↑`/`↓`/`Enter`와 글자(T·I·C·L)로도 고른다. 캔버스 깊이 제한이면 캔버스 항목은 이유와 함께 막는다.
  - 다중 선택에서 끌었다면 새 노드 하나에 고른 노드 모두를 잇는다(각자 잡은 점과 같은 변에서).
- **어느 연결점에 잇나 (사용자 선택: 방식 1, 위치 기준을 네 방향으로):** 잡은 연결점에서 놓은 자리까지 가로·세로 중 더 많이 떨어진 쪽으로 정한다. 오른쪽이면 새 노드의 왼쪽 점, 왼쪽이면 오른쪽 점, 아래면 위쪽 점, 위면 아래쪽 점.
- **배치:** 이어지는 연결점이 놓은 자리에 오도록 놓는다. 유한 캔버스면 범위 안으로 맞춘다. 화면은 움직이지 않는다.

## 접근

- 방식 1(선택됨): 위치 기준. 선이 짧고 꼬이지 않는다. 대각선 근처에서는 변이 쉽게 바뀐다.
- 방식 2: 시작한 변의 반대쪽. 예측은 쉽지만 반대 방향으로 끌면 선이 S자로 꼬인다.

## 테스트

`scripts/test-workspace-editing.ts`: 방향 정하기, 연결점 기준 배치, 노드와 선을 한 문서 변경으로 넣기, 빈 곳에 놓으면 메뉴가 열리고 문서는 그대로, 거의 안 끌었거나 노드 위에 놓으면 메뉴 없음.
