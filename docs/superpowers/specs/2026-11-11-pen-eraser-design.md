# 펜·지우개 도구 설계

## 목적
캔버스 위에 손으로 자유롭게 그리고, 문지른 부분만 지운다. 선 하나하나는 사용자가 고르거나 옮기는 객체가 아니다. 노드 사이에 동그라미, 화살표, 밑그림을 그려 생각을 정리하는 용도다.

## 결정 사항 (사용자 확인)
- 그림은 노드 **뒤 배경**에 깔린다. 노드가 그림을 가릴 수 있다.
- 지우개는 **문지른 부분만** 지운다. 선 중간을 지우면 선이 둘로 나뉜다.
- 펜 색은 연결선과 같은 8색, 굵기는 3단계(가늘게 2 · 보통 4 · 굵게 8, 캔버스 단위)다.
- 저장 방식은 벡터다. 선을 점 목록으로 문서 JSON에 저장하고, 지우개는 선을 잘라낸다.

## 사용 방식
- **도구 막대:** 노드 추가 버튼 아래에 구분선을 두고 펜(`P`)과 지우개(`E`) 버튼을 둔다.
  - 버튼은 `aria-pressed`로 켜짐을 표시한다.
  - 같은 버튼을 다시 누르거나 `Esc`를 누르면 선택 모드로 돌아간다.
- **펜:**
  - 펜이 켜지면 도구 막대 오른쪽에 색 8개와 굵기 3단계를 고르는 칸이 뜬다.
  - 마지막 선택은 localStorage에 기억한다. 읽기와 쓰기가 실패해도 기본값으로 동작한다.
  - 노드 위에서 시작해도 그려진다. 선은 둥근 끝, 부드러운 곡선으로 그린다.
- **지우개:**
  - 포인터 위치에 지우개 범위를 원으로 보여준다. 반지름은 화면 기준 10px이고, 캔버스 단위로는 `10 / zoom`이다.
  - 드래그한 경로에서 반지름 안에 든 구간만 지운다.
- **펜·지우개 모드 공통:**
  - 노드를 선택하거나 옮길 수 없다. 노드 위에 투명한 입력 판을 깐다.
  - 스페이스 드래그와 휠 클릭으로 화면 이동, 휠로 확대·축소가 그대로 된다.
- **되돌리기:** 선 하나, 또는 지우개로 한 번 문지른 것 전체가 Undo 한 단계다.
- **하위 캔버스:** 그림은 하위 캔버스마다 따로 저장된다. 하위 캔버스로 이동해도 도구 선택은 유지된다. 새 하위 캔버스는 그림 없이 시작한다.
- **저장:** 기존 자동 저장을 그대로 탄다.

## 데이터
```ts
WorkspaceDocument.drawing?: { strokes: DrawingStroke[] }

type DrawingStroke = {
  id: string;
  color: ConnectionColor;   // 색 이름(테마 대응). 연결선 팔레트와 같다.
  width: 2 | 4 | 8;
  points: number[];         // [x0, y0, x1, y1, …], 소수 첫째 자리 반올림
};
```
- `drawing`이 없는 이전 문서는 그림 없음으로 연다.
- 한도:

  | 대상 | 최대 |
  | --- | --- |
  | 공간 하나의 선 | 3,000개 |
  | 선 하나의 점 | 4,000개 (숫자 8,000개) |
  | 문서 전체의 점 | 300,000개 |

  한도를 넘는 획은 저장하지 않고 알림을 띄운다.
- 스키마 검사 항목:
  - 색과 굵기가 정해진 값인지
  - 점이 짝수 개이면서 2개 이상인지
  - 좌표가 유한한 수인지
  - 위 한도를 넘지 않는지
  - 선 ID가 공간 안에서 겹치지 않는지

## 구성
- **`drawing.ts`** (React 없음):
  - `appendPoint`: 화면 기준 1.5px보다 가까운 점은 버린다.
  - `simplifyPoints`: RDP 단순화. 끝점을 유지한다.
  - `strokePath`: 점 목록을 SVG path(2차 곡선 중점 연결)로 바꾼다. 점이 하나면 점 모양으로 그린다.
  - `eraseStrokes(strokes, eraserPoints, radius)`: 선의 각 구간을 지우개 경로(선분들)와의 거리로 판정한다. 지워질 구간을 빼고 남은 구간마다 새 선을 만든다. 경계는 보간해서 자른다.
  - 한도 상수와 `countDrawingPoints`.
- **`drawing-layer.tsx`:** 캔버스 변환 div 안, `ConnectionLayer`보다 앞(아래)에 놓는 SVG다. `pointer-events: none`으로 저장된 선과 그리는 중인 선을 그린다.
- **`draw-options.tsx`:** 펜 색과 굵기를 고르는 칸이다. 라디오 그룹 2개로 만든다.
- **`icons.tsx`:** `PenIcon`, `EraserIcon`을 추가한다.
- **`workspace-toolbar.tsx`:** 펜·지우개 토글 버튼을 추가한다.
- **`workspace.tsx`:**
  - `tool` 상태를 추가한다.
  - `Gesture`에 `draw`와 `erase`를 추가한다.
  - 입력 판의 pointerdown에서 이력 `begin`, move에서 `change`, up에서 `commit`을 부른다.
  - 단축키 `P`, `E`, `Esc`를 추가하고 커서를 바꾼다(펜은 crosshair, 지우개는 none에 원 표시).
- **`workspace-schema.ts`:** `drawing` 검사와 전체 점 한도를 추가한다.

## 오류 처리
- 한도 초과: 획을 버리고 알림을 띄운다.
- 포인터가 취소되면(pointercancel, lost capture) 그리던 획을 확정한다. 점이 없으면 이력을 `cancel`한다.
- 지우개로 아무것도 지우지 못한 문지르기는 이력을 `cancel`해서 빈 Undo 단계를 남기지 않는다.
