# 타임랩스

## 왜

프로젝트가 어떻게 만들어졌는지 순서대로 다시 보는 재미 기능. 노드가 하나씩 놓이고, 글이 바뀌고, 펜 획이 그어지는 과정을 짧은 영상처럼 본다.

## 정한 것 (사용자)

- **A(실제 기록)가 기본.** 저장할 때마다 바뀐 부분을 기록하고 그 순서대로 재생한다.
- **B(순서 추정)도 넣는다.** 기록이 시작되기 전에 이미 있던 내용은 그럴듯한 순서로 하나씩 펼쳐 보인다.
- 텍스트는 글자 단위로 보이지 않아도 된다. 저장 시점의 결과만 보인다.
- 펜 그림은 획 단위로, 한 획씩 그어지게 보인다.

## Approaches

| 방식                                             | 장단점                                                     | 결정     |
| ------------------------------------------------ | ---------------------------------------------------------- | -------- |
| 저장마다 바뀐 부분(항목 단위 차이)을 서버에 기록 | 작다. 서버가 저장 때 이전 문서와 비교해 만든다             | **선택** |
| 저장마다 문서 전체를 기록                        | 가장 단순하지만 그림이 많으면 같은 획을 계속 다시 저장한다 | 기각     |
| 화면 녹화(영상)                                  | 프로크리에이트 방식. 용량이 크고 확대하면 흐리다           | 기각     |

## 기록 형식

문서를 "항목" 묶음으로 펼친다. 항목 키와 값:

- `shell|<경로>`: 캔버스 설정과 선택 필드 유무(`{ canvas, drawing, groups, tags }`)
- `order|<경로>`: 노드 순서(ID 목록)
- `node|<경로>|<ID>`: 노드(캔버스 노드는 하위 문서 없이)
- `conn|<경로>|<ID>`: 연결선, `stroke|<경로>|<ID>`: 펜 획, `group|<경로>|<ID>`: 그룹, `tag|<ID>`: 태그

경로는 캔버스 노드 ID를 `/`로 이은 것(루트는 빈 문자열). 한 번의 기록(단계)은 `{ set: {키: 값}, del: [키] }`. 같은 획·노드는 바뀌지 않으면 다시 적지 않는다. 지운 것은 키만 적는다.

## 서버

- 새 표 `project_history`: `id, projectId, version, createdAt, baseline, patch(JSON)`.
- 문서 저장(PUT)이 성공할 때 같은 트랜잭션에서:
  1. 이 프로젝트에 기록이 하나도 없고 이전 문서가 비어 있지 않으면, 이전 문서 전체를 **기준 기록**(`baseline: true`)으로 먼저 남긴다. 기록 시작 전 내용이다.
  2. 이전 문서와 새 문서의 차이를 한 단계로 남긴다(차이가 없으면 남기지 않는다).
- 한 프로젝트에 기록이 2000개를 넘으면 가장 오래된 두 단계를 하나로 합친다(묶기). 중간 과정만 사라지고 결과는 같다.
- `GET /api/projects/{id}/history`: 기록 목록(오래된 순).

## 재생 (브라우저)

- 메뉴 "보기" → "타임랩스". 지금 열린 캔버스의 과정을 재생한다(다른 캔버스만 바뀐 단계는 건너뛴다).
- 단계 목록: 기준 기록은 **B**로 쪼개 여러 단계로 만들고, 그다음 실제 기록, 마지막에 아직 저장 안 된 편집(지금 화면과의 차이)을 붙인다.
- **B 순서:** 캔버스 설정 → 노드를 위→아래, 왼쪽→오른쪽으로 하나씩(양 끝 노드가 다 나온 연결선과 그룹은 그때 함께) → 펜 획은 20개씩. 하위 캔버스는 부모 다음.
- 연출:
  - 새 노드: 살짝 커지며 나타난다. 내용이 바뀐 노드: 잠깐 강조 테두리.
  - 펜 획: 그은 순서대로 선이 그어진다(한 단계 안에서 차례로).
  - 지운 것은 사라진다.
- 단계마다 일정한 시간(기본 0.7초, 획이 많으면 조금 더). 쉬던 시간은 없다.
- 재생 막대: 재생/일시정지, 배속(1×·2×·4×), 진행 막대(끌어서 이동), 닫기(×·Esc). 추정 구간은 진행 막대에 다른 색으로 표시하고 "기록 전 내용은 순서를 추정했어요" 안내.
- 재생 중에는 편집을 막는다(노드·캔버스 입력을 받지 않음). 닫으면 지금 문서로 돌아온다.

## 하지 않는 것

- 글자 단위 타이핑 재현, 영상 파일로 내보내기, 다른 사람과 공유.
- 기능 이전 작업의 실제 순서(기록이 없다).

## 빌더에게 맡기는 것

- 항목 펼치기·되돌리기·차이·합치기·B 단계 만들기는 순수 함수(`timelapse.ts`)로 두고 테스트한다.
- 애니메이션 세부 시간, 재생 막대 모양.
