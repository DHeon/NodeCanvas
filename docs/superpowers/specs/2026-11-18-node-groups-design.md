# 노드 그룹 설계

## 목적

캔버스 위의 관련된 노드들을 한 덩어리로 묶어 보이게 한다. 묶음은 노드들을 여유 있게 감싸는 반투명 영역과 왼쪽 위의 이름 탭으로 보인다. 묶은 뒤에도 노드는 자유롭게 움직이고, 그룹 영역이 노드를 따라 늘어난다. 정리한 생각을 "이건 이 묶음"이라고 표시하면서도 배치의 자유는 잃지 않는 것이 목표다.

## 결정 사항 (사용자 확인)

- 그룹은 따로 먼저 만들지 않는다. 노드를 1개 이상 고른 뒤 **G 키** 또는 **우클릭 메뉴 "그룹화"** 로 만든다.
- 그룹은 묶인 노드들을 여유 공간을 두고 딱 감싸는 **반투명 영역**이고, 왼쪽 위에 **이름 탭**이 있다(사용자 스케치).
- 그룹 밖 노드를 끌어 그룹 영역 위에서 놓으면 그 그룹에 들어간다. 끄는 동안 "들어갈 것" 표시를 준다. 영역은 새 노드에 맞게 바뀐다.
- 그룹 안 노드를 영역 밖으로 끌어도 빠지지 않고 **영역이 따라 늘어난다**.
- 빠지는 방법은 그룹에 속한 노드의 우클릭 메뉴 **"그룹화 해제"** 뿐이다.
- **이름 탭을 끌면 그룹 전체가 이동한다(A).** 그룹 안 빈 곳은 캔버스와 같다(누르면 선택 해제, 끌면 범위 선택).

## 접근 방식

- **선택: 노드가 `groupId`를 갖고, 캔버스는 그룹 이름 목록만 갖는다. 영역은 그릴 때 계산한다.** 노드는 구조상 한 그룹에만 속하고, 노드를 지우거나 복제할 때 따로 정리할 목록이 없다. 노드를 옮기면 영역이 저절로 따라간다.
- 버림: 그룹이 노드 ID 목록을 갖는 방식. 노드를 지우는 모든 동작에서 목록을 함께 고쳐야 해서, 하나라도 빠지면 없는 ID가 남아 자동 저장이 거절된다.
- 버림: 영역 좌표를 저장하는 방식. 노드가 움직일 때마다 영역도 고쳐야 한다.

## 데이터

```ts
NodeBase.groupId?: string;                       // 같은 캔버스의 그룹 ID. 없으면 그룹 없음
WorkspaceDocument.groups?: { id: string; title: string }[];   // 캔버스(공간)마다
```

- 그룹은 공간마다 따로다. 하위 캔버스의 노드는 그 캔버스의 그룹에만 속할 수 있다. 캔버스 노드도 그룹에 들어갈 수 있다.
- 그룹 이름: 앞뒤 공백을 뺀 1–40자, 기본 "그룹"(내 판단). 비우고 적용하면 "그룹"으로 돌아간다.
- 한도: 공간 하나에 그룹 200개(내 판단).
- 스키마: 그룹 ID는 공간 안에서 유일하고, 노드의 `groupId`는 같은 공간의 그룹 목록에 있어야 한다. **멤버가 없는 그룹은 허용**한다(어떤 경로로 멤버가 사라져도 저장이 거절되지 않게). 화면은 멤버 없는 그룹을 그리지 않고, 그룹 편집 함수들은 빈 그룹을 목록에서 정리한다. 빈 목록은 필드를 저장하지 않는다.
- 이전 문서는 그대로 열린다.

## 영역 계산

- `groupBounds(document, groupId)`: 멤버 노드 사각형의 합집합에 사방 **여유 32px**(캔버스 단위, 내 판단)를 더한 사각형. 멤버가 없으면 없음.
- 끄는 중에는 노드의 현재(이동 중) 위치로 계산하므로 영역이 실시간으로 따라 늘어난다.

## 화면

- 그룹은 손그림 위, 연결선·노드 아래에 깔린다.
- 영역: 16px 둥근 모서리, Moss 계열 아주 옅은 채움(약 8%)과 1px 옅은 Moss 테두리. 그룹끼리 겹치면 그대로 겹쳐 보인다.
- 이름 탭: 영역 왼쪽 위 모서리 바로 위에 붙은 작은 탭(스케치처럼). 12–13px 글자, 확대와 무관한 크기는 아니고 캔버스와 함께 커지고 작아진다(노드와 같은 규칙).
- **들어갈 것 표시:** 그룹 없는 노드를 끄는 동안 커서가 어떤 그룹 영역 안에 있으면 그 그룹의 채움이 진해지고 테두리가 Moss Deep으로 바뀐다. 손을 떼면 그 그룹에 들어간다.
- 검색 흐림은 노드만 적용하고 그룹 영역은 그대로 둔다(내 판단).

## 동작

- **만들기:** 노드 1개 이상 선택 → G 또는 우클릭 "그룹화". 새 그룹 `{ id, title: "그룹" }`를 만들고 고른 노드의 `groupId`를 바꾼다. 다른 그룹에 있던 노드는 새 그룹으로 옮겨가고, 그로 인해 빈 그룹은 목록에서 정리된다. 선택은 그대로 둔다. 실행 취소 한 단계.
- **우클릭 메뉴(노드 위):**
  - 우클릭한 노드가 선택에 없으면 그 노드만 선택한 뒤 메뉴를 연다. 선택에 있으면 선택을 유지한다.
  - 항목: "그룹화" (G) — 항상. "그룹화 해제" (Shift+G) — 고른 노드 중 그룹에 속한 것이 있을 때만.
  - 모양과 키보드는 기존 "이어서 만들기" 메뉴와 같은 패턴(↑/↓·Enter·Esc, 바깥 누르면 닫힘). 빈 캔버스 우클릭은 메뉴 없음.
  - 키보드: 노드가 선택된 상태에서 메뉴 키 또는 Shift+F10을 누르면 선택한 노드 근처에 같은 메뉴가 열린다(내 판단).
- **그룹화 해제:** 고른 노드 중 그룹에 속한 노드의 `groupId`를 지운다. 비게 된 그룹은 정리된다. 노드 위치는 그대로다. 실행 취소 한 단계.
- **끌어서 들어가기:** 노드를 끄는 동안 커서 아래 그룹을 찾는다(여러 개 겹치면 나중에 만든 그룹). **끄는 노드가 모두 그룹이 없을 때만** 들어가기가 일어난다(표시도 그때만). 그룹에 속한 노드가 하나라도 섞여 있으면 아무 그룹에도 넣지 않는다. 그룹 멤버와 함께 끌면 그 그룹 영역이 커서 아래로 늘어나기 때문에, 범위 선택이나 Ctrl+A로 함께 옮기다가 의도치 않게 묶이는 것을 막는다(내 판단). 이미 그룹이 있는 노드는 그대로 원래 그룹에 남는다(다른 그룹으로 옮기는 건 해제 후 다시). 끌기와 들어가기는 실행 취소 한 단계.
- **이름 탭:**
  - 끌면 그룹 전체(멤버 모두)가 이동한다. 유한 캔버스면 범위 안으로 맞춘다. 실행 취소 한 단계.
  - 짧게 누르면 그룹 멤버 전체를 선택한다(내 판단: 방향키 이동·삭제·해제를 한 번에 하기 쉬움).
  - 더블클릭하면 이름을 그 자리에서 고친다(Enter·포커스 이동으로 적용, Esc 취소). 이름 바꾸기는 실행 취소 한 단계.
  - 키보드: 탭은 Tab으로 포커스할 수 있는 컨트롤이다. Enter는 이름 고치기, Space는 멤버 전체 선택(이후 방향키로 그룹째 이동)(내 판단).
- **한도:** 공간의 그룹이 200개면 만들기를 하지 않고 알림을 띄운다.
- **펜·지우개:** 그리기 도구가 켜져 있으면 그룹 영역·탭은 입력을 받지 않고 캔버스로 넘긴다.
- **그룹 안 빈 곳:** 캔버스와 같다(범위 선택).
- **복제(Ctrl+D):** 복사본은 원본과 같은 그룹에 들어간다(같은 공간 안에서 복제되므로).
- **삭제:** 멤버를 지우면 그 노드만 사라지고 영역이 줄어든다. 멤버가 모두 사라지면 그룹이 보이지 않는다.
- **공간 이동:** 하위 캔버스로 들어가면 그 공간의 그룹만 보인다.

## 범위 밖

- 그룹 안의 그룹(중첩), 한 노드가 여러 그룹에 속하기.
- 그룹 색 고르기, 그룹 접기·숨기기, 그룹째 복제·삭제 메뉴.
- 노드 위가 아닌 곳(빈 캔버스·연결선)의 우클릭 메뉴.
- 이어서 만들기로 만든 노드를 출발 노드의 그룹에 자동으로 넣기.

## 빌더에게 맡기는 것

- 영역·탭의 정확한 색 농도, 진해지는 표시의 연출(움직임 줄이기 설정 존중).
- 그룹 함수들의 이름과 파일 배치, 우클릭 메뉴 컴포넌트를 "이어서 만들기" 메뉴와 공유할지.
- 탭 끌기와 노드 끌기 코드를 어떻게 함께 쓸지.

## 테스트

- 스키마: `groupId`가 목록에 없으면 거절, 그룹 ID 중복 거절, 이름 길이, 빈 그룹 허용, 이전 문서 통과, 하위 캔버스 노드가 루트 그룹 ID를 가지면 거절.
- 순수 함수: 영역 계산(여유 32px, 멤버 없음), 만들기(다른 그룹에서 옮겨오며 빈 그룹 정리), 해제(빈 그룹 정리), 끌어서 들어가기(그룹 없는 노드만), 커서 아래 그룹 찾기(겹치면 나중 것), 탭으로 그룹 이동(멤버 모두, 유한 캔버스 맞춤), 이름 정리.
- 편집 동작: G·Shift+G 단축키, 우클릭 시 선택 규칙, 끌어서 들어가기와 탭 이동이 각각 실행 취소 한 단계.
