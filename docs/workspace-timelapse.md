# 타임랩스

## 사용

- 메뉴 **보기 → 타임랩스**. 지금 열린 캔버스가 어떻게 만들어졌는지 처음(빈 화면)부터 재생한다. 다 만들어진 모습이 화면에 들어오게 맞춘 뒤 시작한다.
- 노드가 하나씩 커지며 나타나고, 내용이 바뀐 노드는 잠깐 빛나고, 펜 획은 그은 순서대로 그어진다. 지운 것은 사라진다. 글은 글자 단위가 아니라 저장된 시점의 모습으로 바뀐다.
- 재생 막대: 재생/일시정지, 진행 막대(끌어서 이동), 장면 번호, 배속 1×·2×·4×, 닫기.
  - 키보드: `Space` 재생/일시정지, `←` `→` 한 장면씩, `Esc` 닫기.
- 기록이 시작되기 전부터 있던 내용은 **순서를 추정**해서 보인다(위→아래, 왼쪽→오른쪽으로 한 노드씩, 획은 20개씩). 진행 막대에서 황토색 구간이고, 그동안 "기록 전 내용은 순서를 추정했어요"가 뜬다.
- 아직 저장하지 않은 편집도 마지막 장면에 들어간다.
- 재생 중에는 편집할 수 없다(캔버스·도구 막대·메뉴·속성 패널이 입력을 받지 않는다). 가운데 버튼이나 `Space`+끌기, 휠로 둘러보기는 된다. 닫으면 지금 문서로 돌아온다.
- 다른 캔버스만 바뀐 단계는 건너뛴다. 하위 캔버스를 열고 타임랩스를 열면 그 캔버스의 과정만 본다.

## 기록

- 문서를 저장(PUT)할 때마다 서버가 이전 문서와 새 문서의 차이를 `project_history`에 한 줄로 남긴다. 바뀐 게 없으면 남기지 않는다.
- 기록이 하나도 없는 프로젝트에서 처음 저장하면, 그 전 문서를 **기준 기록**(`baseline`)으로 먼저 남긴다. 재생할 때 이 부분이 순서 추정 구간이 된다.
- 한 프로젝트의 기록이 2000줄을 넘으면 가장 오래된 두 줄을 하나로 합친다. 오래된 중간 과정만 뭉쳐지고 결과는 같다.
- 기록은 부가 기능이라 실패해도 저장은 그대로 성공한다(서버 로그에 남는다). 빠진 차이는 다음 저장의 차이에 포함된다.
- 프로젝트를 지우면 기록도 함께 지워진다. `.nono` 내보내기에는 기록이 들어가지 않는다.

## 데이터

문서를 "항목"(키 → 값)으로 펼쳐 비교한다(`timelapse.ts`).

| 키                 | 값                                                         |
| ------------------ | ---------------------------------------------------------- |
| `shell\|경로`      | `{ canvas, drawing, groups, tags }`(캔버스 설정·필드 유무) |
| `order\|경로`      | 노드 ID 순서                                               |
| `node\|경로\|ID`   | 노드(캔버스 노드는 하위 문서 없이)                         |
| `conn\|경로\|ID`   | 연결선                                                     |
| `stroke\|경로\|ID` | 펜 획                                                      |
| `group\|경로\|ID`  | 그룹                                                       |
| `tag\|ID`          | 태그                                                       |

- 경로는 캔버스 노드 ID를 `/`로 이은 것(루트는 빈 문자열).
- 한 단계는 `{ set: [키, 값][], del: 키[] }`. `set`을 객체가 아닌 목록으로 두는 건 Postgres JSONB가 객체 키를 정렬해 그린 순서를 섞기 때문이다.
- `GET /api/projects/{id}/history`: 본인 프로젝트의 기록을 오래된 순으로 `{ history: [{ baseline, patch, createdAt }] }`.
- 재생 장면은 `buildTimelapseFrames(기록, 지금 문서, 캔버스 경로)`가 만든다. 장면 시간은 0.7초에 새 획 하나당 0.05초를 더한다(최대 2초).
