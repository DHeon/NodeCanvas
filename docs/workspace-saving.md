# 작업 공간 저장

편집을 멈추면 약 1.5초 뒤 서버에 자동 저장한다(`use-autosave.ts`). 저장 버튼과 Ctrl/Cmd+S는 "지금 저장"이다. 브라우저 임시 저장·복구는 하지 않는다.

## 저장 흐름

- 편집 중에는 문서를 React 상태로만 관리한다. localStorage·sessionStorage·IndexedDB에 문서를 쓰거나 읽지 않는다.
- 자동 저장·저장 버튼·Ctrl+S는 모두 같은 `saveWorkspace`를 쓴다. 그 시점의 문서와 버전 번호를 PUT 요청으로 전송한다.
- 드래그·이미지 업로드·저장 중에는 자동 저장을 미뤘다가 끝나면 저장한다.
- 통신·서버 오류(5xx)는 10초 뒤 자동으로 다시 시도한다. 400·401·403·404는 다시 시도하지 않고 오류를 보여준다.
- 앱 안에서 다른 화면으로 이동할 때(뒤로 가기 포함) 남은 변경은 `keepalive` 요청으로 마지막으로 보낸다. 본문이 64KB를 넘으면 브라우저가 거절할 수 있으므로 최선 노력이다.
- 상태 표시: "편집 중…" → "저장 중…" → "저장됨 · 시각".
- 저장 성공 후 해당 스냅샷을 저장 완료 기준으로 삼는다. 요청 도중 추가 편집한 내용은 미저장 상태로 남는다.
- 저장 중 중복 요청과 드래그 중 저장을 막는다.
- 서버 문서 버전이 다르면 409로 거절하고 현재 화면의 편집 내용을 유지한다. 자동으로 덮어쓰지 않고 충돌 패널(`conflict-panel.tsx`)에서 사용자가 고른다: 내 편집 JSON 내려받기 / 서버 버전 불러오기(새로고침) / 내 편집으로 덮어쓰기(최신 버전 번호를 확인한 뒤 저장).
- 응답을 놓친 요청은 다음 저장(자동 재시도 포함) 때 GET으로 확인한다. 이미 같은 내용이 저장됐다면 버전을 맞춘 뒤 필요할 때만 다음 내용을 저장한다.
- 저장 실패 시 편집 내용은 현재 화면에만 남는다. 새로고침·종료하면 잃을 수 있다.
- 저장 전 새로고침·탭 닫기와 프로젝트 목록 이동의 경고는 유지한다.
- 파일 메뉴의 "JSON으로 내려받기"로 하위 공간까지 포함한 문서를 백업할 수 있다.

## 관련 코드

- `workspace.tsx`: 저장 상태, 저장 버튼·Ctrl+S, 이탈 경고, 충돌 처리.
- `use-autosave.ts`: 편집이 멈춘 뒤 저장, 바쁠 때 미루기, 실패 시 재시도 간격.
- `workspace-save-client.ts`: GET/PUT 통신, 응답 검증, 요청 시간 제한.
- `workspace-history.ts`: 편집 이력과 실행 취소·다시 실행. 저장 요청을 보내지 않는다.
- `src/app/api/projects/[projectId]/document/route.ts`: 로그인·소유권·데이터 형식·문서 버전 검증.

과거 브라우저 임시본은 자동으로 삭제하지 않았다. 현재 앱은 그 데이터를 사용하지 않는다.

## localhost와 IP 접속

- `.env`의 `BETTER_AUTH_URL`은 기본 인증 주소다. 추가로 허용할 주소는 `APP_TRUSTED_ORIGINS`에 쉼표로 구분해 설정한다.
- `src/lib/app-origins.ts`에서 만든 공통 목록을 Better Auth의 `trustedOrigins`와 문서 저장 API의 Origin 검사에 함께 사용한다.
- Next.js 개발 서버의 `allowedDevOrigins`도 같은 목록의 호스트만 허용한다. Server Actions의 동일 출처 검사는 유지한다.
- 주소는 프로토콜과 포트까지 일치해야 한다. IP가 바뀌면 `.env` 목록도 수정하고 서버를 재시작한다. 프로덕션 실행은 재빌드도 필요하다.
- IP 접속을 받으려면 서버를 `npm run dev -- --hostname 0.0.0.0` 또는 빌드 후 `npm run start -- --hostname 0.0.0.0`으로 실행한다. 방화벽·공유기 설정은 별도다.
- localhost와 IP의 로그인 쿠키는 각각 보관되므로 주소별로 로그인한다. 와일드카드 허용이나 CSRF 검사 해제는 하지 않는다.

## 편집 이력과 저장의 관계

- 실행 취소 이력은 현재 화면의 메모리에 최대 100단계만 보관한다. 새로고침하면 사라진다.
- 노드 생성·삭제, 이동·크기 조절, 제목·본문 편집을 되돌릴 수 있다. 선택 상태와 카메라 이동은 이력에 포함하지 않는다.
- 이동·크기 조절은 드래그 한 번, 텍스트 편집은 입력칸에 들어갔다 나오는 한 번을 이력 하나로 묶는다.
- 입력칸 안의 Ctrl+Z는 브라우저 기본 텍스트 실행 취소를 유지한다. 입력칸 밖에서는 Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y로 작업 공간 이력을 조작한다.
- 실행 취소로 마지막 저장 스냅샷에 돌아오면 미저장 표시가 해제된다. 그 밖의 실행 취소·다시 실행 결과도 자동 저장된다.
