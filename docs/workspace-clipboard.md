# 노드 복사·잘라내기·붙여넣기와 우클릭 메뉴

## 사용

- **복사·잘라내기:** 노드를 고르고 `Ctrl+C` / `Ctrl+X`, 또는 우클릭 메뉴. 고른 노드끼리의 연결선과 하위 캔버스 내용도 함께 담긴다.
  - 앱 안(같은 탭)에만 기억한다. 새로고침하거나 다른 프로젝트로 가면 사라진다.
  - 시스템 클립보드에는 노드의 글만 들어간다(다른 프로그램에 붙이면 글만 나온다).
  - 잘라내기는 실행 취소 한 단계이고, 되돌려도 클립보드는 남는다.
- **붙여넣기:** `Ctrl+V`는 마우스 자리, 메뉴는 우클릭한 자리에 묶음의 가운데가 온다. 마우스가 캔버스 밖이면 화면 가운데.
  - 유한 캔버스면 묶음째 캔버스 안으로 민다. 다른 하위 캔버스에도 붙일 수 있다.
  - 붙인 노드들이 새로 선택된다. 실행 취소 한 단계.
  - 그룹: 통째로 고른 그룹은 같은 이름의 새 그룹으로, 낱개 노드는 붙인 자리가 그룹 영역 안이면 그 그룹으로 들어간다. 일부만 고른 그룹 멤버는 그룹 없이 붙는다.
  - 노드를 복사한 뒤 다른 곳에서 이미지나 주소를 복사했다면 `Ctrl+V`는 그쪽(이미지 노드·링크 노드)을 따른다. 시스템 클립보드의 글이 복사한 노드의 글과 같을 때만 노드를 붙인다.
- **글 붙여넣기:** 주소가 아닌 일반 글을 캔버스에 붙이면 그 글이 든 텍스트 노드(320×220, 제목 없음)가 생긴다. 그룹 영역 위면 그 그룹에 들어간다. 빈 글은 무시.
  - 앱 안 글 칸에서 글자를 복사·잘라내면 복사해 둔 노드는 잊고 그 글을 기억한다. 그래서 메뉴의 붙여넣기도 예전 노드가 아니라 그 글로 텍스트 노드를 만든다.
  - 한계: 다른 프로그램에서 복사한 글은 앱이 알 수 없어(권한 창을 피하려고 메뉴는 시스템 클립보드를 읽지 않는다) 메뉴는 앱이 기억한 것을 붙인다. `Ctrl+V`는 늘 실제 클립보드를 따른다.
  - 한도(노드 1000개·그림 점·그룹 200개·깊이 8단계)를 넘으면 붙이지 않고 알림을 띄운다.
- **글 칸:** 텍스트 노드 본문처럼 노드 안 글 칸은 글자를 드래그로 골랐을 때만 `Ctrl+C/X`가 글자를 복사한다. 커서만 있으면 노드를 복사한다. `Ctrl+V`는 글 칸에서는 늘 글자를 붙인다.

## 우클릭 메뉴

| 우클릭한 곳                                    | 메뉴                                                                          |
| ---------------------------------------------- | ----------------------------------------------------------------------------- |
| 노드(선택에 없으면 그 노드만 선택)             | 잘라내기 · 복사 · 붙여넣기 · 그룹화 (+ 그룹 멤버가 있으면 그룹화 해제) · 검색 |
| 그룹 이름 탭                                   | 그 그룹을 선택하고 위와 같은 메뉴                                             |
| 빈 곳, 선택 있음                               | 선택을 그대로 두고 위와 같은 메뉴                                             |
| 빈 곳, 선택 없음                               | 붙여넣기                                                                      |
| 글자를 고른 글 칸이 있을 때(어디를 우클릭하든) | 글자 잘라내기 · 복사 · 붙여넣기. 우클릭해도 드래그한 선택이 풀리지 않는다     |
| 노드 밖 글 칸(고른 글자 없음)                  | 메뉴 없음                                                                     |

- 글자 메뉴는 포커스를 글 칸에 둔 채 열려서, 메뉴가 떠 있는 동안에도 드래그한 선택 표시가 그대로 보인다. 화살표 키를 누르면 메뉴로 넘어가고, `Esc`는 닫고, 다른 키를 누르면 메뉴를 닫고 글 칸에 그대로 입력된다.
- "검색"은 고른 노드 안에서만 찾는 검색창을 우클릭한 자리에 연다(`workspace-tags-search.md`).
- 우클릭은 포커스를 옮기지 않는다. 그래서 여러 개 고른 상태로 노드 본문 위를 우클릭해도 선택이 그 노드 하나로 줄지 않는다.
- 메뉴 키·`Shift+F10`: 선택이 있으면 첫 노드 옆에 노드 메뉴, 없으면 화면 가운데에 붙여넣기 메뉴.
- 펜·지우개 도구일 때와 끄는 중에는 열리지 않는다. 작업영역에서는 브라우저 기본 메뉴를 막는다.
- 글자 메뉴의 붙여넣기는 브라우저가 클립보드 읽기 권한을 물을 수 있다. 거절하면 "붙여넣기는 Ctrl+V를 써 주세요."

## 코드

- `node-clipboard.ts`: `selectedGroupIds`, `makeClip`, `pasteClip`, `PASTE_ERROR_NOTICES`.
- `keyboard-targets.ts`: `copiesNodes`, `hasSelectedText` (글 칸 규칙).
- `node-context-menu.tsx`: 항목 데이터와 `onSelect(id)`를 받는 메뉴.
- `workspace.tsx`: `handleCopy`/`handleCut`/`handlePaste`, `pasteAt`, `openContextMenuAt`, `contextMenuItems`, `runMenuAction`.
