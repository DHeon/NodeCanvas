# 노드 태그와 검색

## 사용

- **태그 붙이기:** 노드를 고르면 속성 패널 "태그" 칸에서 이름을 쓰고 `Enter`.
  - 같은 이름의 태그가 있으면 그것을 붙이고, 없으면 새로 만든다(대소문자 무시).
  - 입력 중 이름이 맞는 기존 태그를 최대 8개 권한다. `↑`/`↓`로 고르고 `Enter`.
  - 한글 조합을 끝내는 `Enter`는 태그를 만들지 않는다.
  - 앞의 `#`은 떼고 저장한다(`#기획` → `기획`).
  - 칩의 `×`로 떼고, 칩을 누르면 8색 팔레트에서 색을 바꾼다.
- **여러 노드에 한 번에:** 노드 여럿을 고르면 "공통 태그" 칸이 나온다.
  - 모두에 붙은 태그는 진하게, 일부에만 붙은 태그는 흐리게(50%) 보인다.
  - 흐린 칩을 누르면 나머지 노드에도 붙는다. `×`는 선택한 모두에서 뗀다.
  - 태그가 가득 찬(20개) 노드는 건너뛰고 알림으로 개수를 알린다.
- **노드 표시:** 노드 머리 오른쪽에 태그 색 점이 최대 3개, 넘치면 `+N`. 마우스를 올리면 태그 이름이 보인다.
- **관리:** 메뉴 막대 "태그"에서 프로젝트의 모든 태그를 본다.
  - 이름 바꾸기(`Enter`·포커스 이동으로 적용, `Esc` 취소), 색 바꾸기, 쓰는 노드 수, 지우기.
  - 노드에 붙은 태그를 지우면 확인을 묻고, 모든 캔버스의 노드에서 뗀다.
- 붙이기·떼기·이름·색·지우기는 각각 실행 취소 한 단계다.

## 검색

- `Ctrl/Cmd + F` 또는 헤더의 돋보기로 캔버스 오른쪽 위에 검색 패널을 연다.
  - 입력칸 안에서도 브라우저 찾기 대신 이 패널이 열린다.
- **검색어 규칙:**
  - 띄어쓰기로 나눈 낱말이 **모두** 들어 있어야 한다(대소문자 무시).
  - 낱말은 제목, 태그 이름, 텍스트 본문, 링크 주소와 미리보기 제목에서 찾는다.
  - `#`으로 시작하는 낱말은 그 글자로 **시작하는** 태그가 붙은 노드만 찾는다(`#디` → `디자인`).
  - 마지막 낱말이 `#`으로 시작하면 태그를 권하고, `Tab`이나 클릭으로 채운다.
- 프로젝트 전체(모든 하위 캔버스)를 찾는다.
- **고른 노드 안에서 찾기:** 노드 여럿을 고르거나 그룹 탭을 고른 뒤 우클릭 → "검색". 우클릭한 자리에 검색창이 뜨고, 그때 고른 노드들(캔버스 노드면 그 안 모든 깊이까지)에서만 찾는다.
  - 캔버스·노드·패널 등 창 밖을 누르거나 `Tab`으로 나가면 창이 닫힌다(결과·버튼을 누를 때는 남는다). 다른 창·탭으로 전환한 것은 닫지 않는다.
  - 범위는 연 순간의 선택으로 고정된다(결과를 눌러 선택이 바뀌어도 그대로).
  - 검색어 규칙·흐림·이동은 전체 검색과 같다. 범위 밖 노드는 흐려진다.
  - 창 위의 "전체에서 찾기"로 범위를 풀 수 있다. `Ctrl/Cmd + F`나 돋보기는 늘 전체 검색을 오른쪽 위에 연다.
  - 지금 캔버스의 결과가 먼저, 그다음 얕은 캔버스 순서다.
  - 최대 100개까지 보이고, 넘치면 검색어를 좁히라고 안내한다.
  - 입력은 150ms 뒤에 반영한다.
- **캔버스 표시:**
  - 결과가 아닌 노드는 25%로 흐려진다. 양 끝이 모두 흐린 연결선도 흐려진다. 손그림은 그대로다.
  - 하위 캔버스 안의 결과는 그 캔버스 노드가 대신 결과로 남고, "N개 찾음" 배지를 단다.
  - 목록 항목을 가리키면(또는 `↑`/`↓`) 캔버스의 그 노드가 Moss Deep 링으로 빛난다.
- **이동:** 항목을 누르거나 `Enter`를 누른다.
  - 그 노드가 있는 캔버스로 들어가 노드를 화면 가운데에 두고 선택한다.
  - 펜·지우개 모드였다면 선택 모드로 돌아간다. 패널은 열린 채로 남는다.
- `Esc`나 `×`로 닫으면 검색어를 비우고 흐림을 걷는다.
- 검색은 문서를 바꾸지 않으므로 실행 취소 이력에 남지 않는다.

## 데이터

```ts
WorkspaceDocument.tags?: TagDefinition[]   // 루트 문서에만
TagDefinition = { id: string /* uuid */, name: string, color: ConnectionColor }
NodeBase.tags?: string[]                   // 태그 ID 목록
```

- 태그 목록은 프로젝트에 하나다. 노드는 ID만 가지므로 이름·색을 바꾸면 모든 캔버스에 함께 반영된다.
- 새 태그 색은 가장 덜 쓰인 팔레트 색이다(같으면 팔레트 순서).
- 빈 목록은 저장하지 않는다(마지막 태그를 떼면 `tags` 필드가 사라진다).
- 한도:

  | 대상             | 최대                    |
  | ---------------- | ----------------------- |
  | 프로젝트의 태그  | 200개                   |
  | 노드 하나의 태그 | 20개                    |
  | 태그 이름        | 1–30자, 공백과 `#` 없이 |

- 스키마(`workspace-schema.ts`) 검사 항목:
  - 태그 목록은 루트에만 있다.
  - 태그 ID·이름(대소문자 무시)이 겹치지 않는다.
  - 노드의 태그 ID가 목록에 있고, 한 노드 안에서 겹치지 않는다.

## 코드

- `tags.ts`: 이름 정리, 만들기·붙이기·떼기·이름·색·지우기, 사용 수. 모두 순수 함수다.
- `search.ts`: 검색어 해석, 전체 트리 검색(범위 `SearchScope`로 좁히기), 캔버스 노드 배지 수.
- `tag-input.tsx`: 속성 패널의 칩과 자동완성 입력.
- `search-panel.tsx`: 검색 패널. `workspace.tsx`가 흐림·강조·이동을 맡는다.
- `workspace-menu.tsx`: 메뉴 막대 "태그" 관리.
